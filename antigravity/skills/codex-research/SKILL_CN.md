# Codex 深度调研技能 (Codex Research)

## 技能定位

本技能通过调用本地 `codex exec` CLI，将深度外部调研、权威事实核验与学术文献考证委派给 OpenAI Codex。与 Codex 端的 `antigravity-writing` 形成互补的跨智能体协作闭环：
- **Antigravity**：负责主流程推进、交互提问、数学/具身控制推导、本地代码操作与综合归纳；
- **Codex (GPT)**：作为外部高可靠调研智囊，提供低幻觉事实核验、跨源文献比对与结构化调研报告。

---

## 典型适用场景

1. **前沿技术事实核查**：遭遇未确证的外部大模型架构、闭源黑盒、争议性技术概念，避免本地直接脑补产生幻觉。
2. **多源文献与背景调研**：需要大范围检索论文、官方技术规范、Release Notes 或 Issues，但不想将海量噪音塞入主上下文。
3. **权威交叉审计**：在给出具有确定性论断之前，先让 Codex 做一遍客观真实性审计与证据链核对。

---

## 调用方式与参数规范

### 1. 基础调用

在受信任路径（默认 `/home/hac/labflow`）执行非交互式 `codex exec`：

```bash
codex exec -m gpt-6-luna -c service_tier="fast" -C /home/hac/labflow --skip-git-repo-check "PROMPT"
```

* **模型选择**：默认使用 `gpt-6-luna` 配备 `service_tier="fast"`。若当前账号权限受限（如提示 `model_not_found`），平滑回退至验证可用的 `gpt-5.6-sol`。
* **大文本输出保护**：若预期调研报告篇幅较长，附加 `-o /tmp/codex_research_<id>.md` 写入独立文件再进行读取。

### 2. 会话复用与链式追问

同一调研主题需要多轮深入时，直接使用 session 恢复命令，无需重新传输前情提要：

```bash
codex exec resume --last "基于刚才关于注意力机制的结论，进一步核验其 KV Cache 压缩算法的具体实现..."
```

## 委托提示词契约（Contract）

给 Codex 的 Brief 应遵循“约束完备”原则：
1. **明确目标**：具体核查哪个型号/算法，核心疑点是什么；
2. **强制事实分级**：要求 Codex 明确区分【白纸黑字的确凿事实】、【学术界/社区的技术推测】与【查无此项的错误名称】；
3. **索要硬凭据**：必须附带论文标题、arXiv 编号、官方发布链接或规范原文引用；
4. **拒绝空洞套话**：直奔架构与技术细节。
